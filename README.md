# Editable Resume Builder by M Haris (Milestone 5)

## Overview
The **Editable Resume Builder** is a dynamic web application that allows users to create, generate, and edit resumes interactively. This project is part 5 of the milestone-based interactive resume builder.

## Features
- User-friendly interface
- Input fields for personal information, education, experience, and skills
- Profile picture upload functionality
- Real-time resume generation
- Inline editing of resume sections
- Validation for required fields
- Modern responsive design

## Technologies Used
- HTML5
- CSS3
- TypeScript

- See The project:[https://hackthon-giaic-milestone-no-5.vercel.app/]

## How to Run the Project
1. Clone the repository.
2. Make sure you have a local server environment like **Live Server** or any static file server.
3. Open the `index.html` file in your browser.

## Folder Structure
```
📁 Project Directory
│   index.html        # Main HTML file
│   style.css         # Stylesheet
│   main.ts           # TypeScript file
└── README.md         # Documentation
```

## Usage
1. Fill out the form with your personal information.
2. Click on the **Generate Resume** button.
3. The resume will be generated below the form.
4. Click on **Edit Resume** to modify any section inline.
5. Click on **Save Resume** to save the changes.

## Prerequisites
- Basic knowledge of HTML, CSS, and TypeScript.
- TypeScript compiler installed globally.
